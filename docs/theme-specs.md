## App Interface Themes

All app themes implement the same debate page structure:
- Header with nav and user dropdown
- Debate title, description, sides (A vs B), meta info
- Stance summary bar (blue/red/gray proportional)
- 4 clickable view tabs: Thread | Sides | Best Exchanges | Verdict
- Thread view with nested comments, stance badges, trust tiers, taxonomy tags, votes, burden of proof
- Sides view with 2-column layout
- Best exchanges with paired cards
- Verdict with tally bar, live badge, voter stats, vote form

## Admin Dashboard Themes

All admin themes implement the same dashboard structure:
- Collapsible sidebar with 7 nav sections (Dashboard, Quarantine Queue, Reports, Users, Debates, Analytics, Settings)
- Top bar with search and notifications
- Dashboard overview with stat cards, moderation bar chart, activity feed, trust tier distribution
- Quarantine queue with flagged comment cards and approve/remove actions
- User management table with tier badges and action dropdowns
- Reports panel with report cards
- Debates management table with status controls
- Analytics with health metrics, engagement charts, vote/taxonomy distributions
- Settings panel with moderation configuration
